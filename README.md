## 📦 Покрокова інструкція запуску

### Крок 1. Встановіть Python

1. Перейдіть на https://www.python.org/downloads/
2. Завантажте **Python 3.11** або новіший (кнопка "Download Python 3.x.x")
3. Запустіть інсталятор
4. ⚠️ **ОБОВ'ЯЗКОВО** поставте галочку **"Add Python to PATH"** перед натисканням Install
5. Натисніть "Install Now"

---

### Крок 2. Встановіть необхідні бібліотеки

1. Відкрийте **Командний рядок** (Win + R → введіть `cmd` → Enter)
2. Перейдіть у папку проєкту:
   ```
   cd Шлях\до\папки\lab_app
   ```
   Наприклад:
   ```
   cd C:\Users\YourName\Desktop\lab_app
   ```
3. Встановіть бібліотеки:
   ```
   pip install -r requirements.txt
   ```
4. Зачекайте завершення (1–3 хвилини)

---

### Крок 3. Запустіть додаток локально

У тому ж командному рядку:
```
streamlit run app.py
```

Браузер відкриється автоматично за адресою: http://localhost:8501

---

### Крок 4. Розгортання в Інтернеті (для розподіленого опитування)

#### Варіант A — Streamlit Cloud (безкоштовно, рекомендується)

1. Зареєструйтесь на https://github.com (якщо немає акаунта)
2. Створіть новий репозиторій (кнопка "+" → "New repository")
3. Назвіть `lab-voting` → Create repository
4. Завантажте файли `app.py` та `requirements.txt` до репозиторію (кнопка "uploading an existing file")
5. Перейдіть на https://share.streamlit.io
6. Натисніть "New app" → оберіть ваш репозиторій → файл `app.py` → Deploy
7. Через 1–2 хвилини отримаєте публічне посилання виду:
   `https://yourname-lab-voting-app-xxxx.streamlit.app`
8. Надішліть це посилання експертам для голосування!

> ⚠️ **Важливо:** При розгортанні на Streamlit Cloud файл `data.json` не збережеться
> після перезапуску. Для постійного зберігання додайте Google Sheets (інструкція нижче).

#### Варіант B — Запуск локально + ngrok (тунель до Інтернету)

1. Завантажте ngrok: https://ngrok.com/download
2. Запустіть додаток: `streamlit run app.py`
3. В іншому вікні: `ngrok http 8501`
4. Отримаєте публічне посилання — поділіться з експертами

## 📋 Порядок роботи

### ЛР1:
1. Всі 21 експерт відкривають посилання
2. Кожен обирає своє ім'я зі списку та голосує (ТОП-3 країни)
3. Викладач переглядає результати на вкладці "Результати ЛР1"
4. Повний протокол з іменами — у вкладці "Адмін"

### ЛР2:
1. Перегляньте ядро лідерів (вкладка "Результати ЛР1")
2. Кожен експерт голосує за 2–3 евристики (вкладка "Евристики - голосування")
3. Перейдіть на "Застосування евристик" → збережіть фінальну підмножину
4. На вкладці "Генетичний алгоритм" → налаштуйте параметри → запустіть

## ❓ Часті питання

**Питання:** Після перезапуску сервера дані зникли.  
**Відповідь:** Перед закриттям завантажте `data.json` через Адмін-панель.

**Питання:** Як додати свої імена до списку?  
**Відповідь:** Відредагуйте список `EXPERTS` у файлі `app.py`.

**Питання:** Як змінити список країн?  
**Відповідь:** Відредагуйте список `OBJECTS` у файлі `app.py`.
